## Project Description

The Student Grade Calculator is a Python-based program that calculates the total marks, percentage, grade, and pass/fail result of students based on marks obtained in five subjects.

The program also allows multiple students to be entered using loops and validates marks to ensure they are between 0 and 100.

## Features

- Accepts student name and marks in five subjects.
- Calculates total marks.
- Calculates percentage.
- Assigns grades automatically.
- Displays Pass or Fail result.
- Validates incorrect marks and non-numeric input.
- Supports multiple students using loops.

## Grading Criteria

| Percentage | Grade |
|---|---|
| 85 and above | A |
| 70–84 | B |
| 55–69 | C |
| 40–54 | D |
| Below 40 | F |

**Passing Criteria:** A student passes with 40% or more.
